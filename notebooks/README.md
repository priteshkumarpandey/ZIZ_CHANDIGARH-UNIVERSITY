# Exploratory Data Analysis Notebooks

This directory contains exploratory data analysis (EDA) and experimental notebooks for the GlucoTwin project.

- `01_eda_cgm_distributions.ipynb`: Analysis of continuous glucose monitoring time series, sampling frequencies, and excursion distributions across personas.
- `02_indian_meal_glycemic_index.ipynb`: Exploration of carbohydrate loads, glycemic index, and fiber buffering across regional Indian food profiles.

All core training and serving logic resides under `src/glucotwin/` to ensure production grade maintainability.
